# Templates

Operational artifacts that operationalize the Commons FinOps methodology. Battle-tested in real organizations.

## Planned templates (roadmap)

These templates are in active development and will be added as they are documented and de-identified from their source organizations:

- [ ] Satellite intake checklist (operationalizes the four core intake risks)
- [ ] Chart of accounts shape for a fiscal sponsor (with class/project dimension)
- [ ] Sanctions schedule (graduated, written before first sanction needed)
- [ ] Conflict resolution path (low-cost, accessible, internal)
- [ ] Monitoring cadence calendar (daily / weekly / monthly / quarterly / annual)
- [ ] Treasury policy (fiat plus digital assets, with named custodians and signing thresholds)
- [ ] Funder due diligence packet (one-page summary plus supporting evidence)
- [ ] Reconciliation discipline checklist (ledger vs platform vs bank vs export)

## How to contribute a template

See [`CONTRIBUTING.md`](../CONTRIBUTING.md). Templates should come from a real operating context and include a brief note on where they were used.
